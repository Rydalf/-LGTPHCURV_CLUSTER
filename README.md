# %LGTPHCURV_CLUSTER
Placeholder repository for potentially hosting a modified version of the %LGTPHCURV9 SAS macro.

This SAS macro adds the ability to specify a robust sandwich covariance matrix (the using COVS(AGGREGATE) PROC PHREG option) to account for clustering. %LGTPHCURV_CLUSTER accounts for clustering by the variable passed by the CLUSTER= option. No other changes are made to the macro. 

The original %LGTPHCURV9 macro was produced to assess non-linear exposure-response relations and nice graphs for logistic and proportional hazards models in SAS, and was created by Ruifeng Li, Ellen Hertzmark, Mary Louie, Linlin Chen, and Donna Spiegelman in 2011. A link to the original macro's details can be found here: https://ysph.yale.edu/cmips/research/software/analysis-graphics/lgtphcurv9/ .
